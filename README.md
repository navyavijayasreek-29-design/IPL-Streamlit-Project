# IPL Data Analysis and Visualization

## Project Description

This project is a Multi-Page Streamlit Application for
IPL Data Analysis and Visualization.

The application allows users to explore IPL match data,
perform data analysis, and view interactive visualizations.

## Objectives

- Explore IPL match data
- Analyse teams and seasons
- Calculate important IPL statistics
- Create interactive visualizations
- Understand IPL match trends

## Technologies Used

- Python
- Pandas
- Streamlit
- Matplotlib
- Plotly

## Dataset

IPL 2008 2026 Merged.csv

## Application Pages

1. Login / Sign In
2. About Project
3. Data Analysis
4. Data Visualization
